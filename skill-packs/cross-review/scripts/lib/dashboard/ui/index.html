Follow reviews
When on, every review that starts opens here in your browser so you can watch it. Starts the dashboard if it is not running; it closes itself after 30 minutes with no page open.
Follow plans
When on, each plan loop-plan finishes opens here in your browser, on its Plan tab, so you can read it before you approve it. Starts the dashboard the same way as Follow reviews.
Plans in git
Plans live in .cross-review/plans/. On adds an exception to .cross-review/.gitignore so loop-implement commits each plan with its phases; sessions and settings stay out of git. Turning it off later does not remove plans already committed: run git rm --cached on them.
